## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：CONFIG の num_train_epochs を20から10に変更した。学習回数以外の設定は変更せず、ランタイムを再起動して再学習した。学習回数の違いがTraining Loss、学習時間、回答精度に与える影響を比較した。
- 結果（比較表や数字）：評価項目

| 評価項目 | 20エポック | 10エポック |
|---|---:|---:|
| 学習データ数 | 14件 | 14件 |
| ステップ数 | 40 | 20 |
| 学習時間 | 236秒 | 114秒 |
| 最終Training Loss | 0.013856 | 0.099734 |
| format_rate | 100% | 100% |
| content_rate | 90.48% | 85.71% |
| both_rate | 90.48% | 85.71% |
| 内容正解数 | 19/21問 | 18/21問 |
| 退行した質問 | 0件 | 0件 |

エポック数を20から10に減らした結果、学習時間は236秒から114秒へ約52%短縮された。一方、形式遵守率は100%を維持し、内容正解率の低下も21問中1問にとどまった。

最終Training Lossは20エポックの方が低かったが、評価データに対する内容正解率の差は比較的小さかった。このことから、学習回数を増やしてLossを下げても、必ずしも同じ割合で回答精度が向上するわけではないことがわかった。

今回の条件では、10エポックでも回答形式を十分に学習できており、学習時間と性能のバランスを考える重要性を確認できた。

エポック数を半分にした結果、学習時間は236秒から114秒へ約52%短縮された。一方、形式遵守率は100%を維持し、内容正解率の低下は21問中1問にとどまった。

最終Training Lossは20エポックの方が低かったが、評価データの内容正解率には大きな差がなかった。このことから、学習を長く続けてLossを下げることが、必ずしも同じ割合で回答精度の向上につながるわけではないとわかった。

今回の条件では、10エポックでも回答形式を十分に学習できており、学習時間と性能のバランスを考える重要性を確認できた。ただし、評価対象は21問と少なく、10エポックが最適であるとまでは判断できない。

- ファインチューニングが向く場面・向かない場面についての考察：ファインチューニングは、JSONなどの回答形式の統一や、特定の業務に合わせた回答パターンを習得させる場面に向いている。今回の演習でも、LoRAによってモデル全体の約0.84%の追加パラメータを学習するだけで、形式遵守率を100%まで改善できた。
